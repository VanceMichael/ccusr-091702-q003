# 无障碍设施整改中枢

本服务用于公共设施缺陷聚合、责任认领和复验闭环。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：辖区、设施版本、巡查批次、原始报告、整改周期、临时占用、复验记录。

相似报告可归入一个缺陷但原始陈述不可丢失；复发开启新周期；临时占用按批准时窗生效；关闭缺陷需要辖区和专业范围匹配。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/accessibility_remediation.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
